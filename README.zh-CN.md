## 🌙 在俱乐部中游玩

点击游戏卡片，会打开占满窗口的播放器。使用**返回**回到合集，点击**独立窗口**可在新标签页打开同一个 Cloudflare 游戏。关闭播放器时会卸载 iframe，让游戏音乐一起停止。按住修饰键点击链接，也保留浏览器原有的打开方式。

可使用各游戏的屏幕按钮或其说明中的键盘操作；音乐由玩家主动操作后开始。游戏会在浏览器允许时保存本地进度，嵌入场景的存储可能受浏览器隔离策略影响；需要直接访问时可选择独立窗口。十二个真实游戏链接已写在原始 HTML 中，合集脚本不可用时仍能打开链接；游戏运行本身需要 JavaScript。

## 🛠️ 本地运行合集

在本仓库根目录运行：

```sh
python3 -m http.server 8080
```

打开 **http://localhost:8080/** 即可。无需安装依赖，也没有构建步骤。合集页面使用本地 HTML、CSS、JavaScript 与 SVG 插画；可玩的游戏仍从已有 `*.crazy3d.org` 域名加载，因此加载游戏需要联网。

可以使用下面的命令检查脚本语法：

```sh
node --check club.js
```

## 🚀 静态部署

把仓库根目录作为静态目录发布即可。使用 **GitHub Pages** 时，选择 **Deploy from a branch → main → /(root)**，并保留 `.nojekyll`。使用 **Cloudflare Pages** 时，按静态 HTML 项目配置，发布包含 `index.html` 的目录；如需构建命令，可使用不执行构建的 `exit 0`。

合集已通过 GitHub Pages 发布：**[打开午夜糖果俱乐部](https://ashintop.github.io/halloween-games/)**。上面十二款游戏的链接已经指向实际在线的 Cloudflare 地址。合集资源采用相对路径，也可以部署在 GitHub Pages 的仓库子路径下。

托管参考文档: [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) · [Cloudflare Pages — Static HTML](https://developers.cloudflare.com/pages/framework-guides/deploy-anything/).

## 📁 轻量、独立的合集项目

- `index.html` — 完整静态目录、十二款在线链接、双语文案、内联插画与 `ItemList` 元数据。
- `club.css` — 原有俱乐部风格、响应式卡片、焦点样式及播放器布局。
- `club.js` — 语言切换、筛选、弹窗控制与渐进增强的 iframe 启动。
- `club.svg` / `favicon.ico` — 俱乐部的小幽灵图标。
- `.nojekyll` — 让 GitHub Pages 直接发布静态文件。

每款游戏源码保留在各自链接的仓库中。合集没有复制十二套游戏源码、媒体归档或部署凭证。修改卡片时，编辑 `index.html` 内的实际链接及 `data-en` / `data-zh` 双语文案即可。
