# 🎃 Jogos de Halloween — 12 minijogos grátis para navegador

**[🎃 Jogue os 12 jogos de Halloween on-line →](https://ashintop.github.io/halloween-games/)**

**Midnight Candy Club** reúne doze jogos acolhedores de Halloween: números de abóbora, paciência assombrada, blocos de doces, fantasmas espelhados, música de monstros, ritmo e pequenas aventuras 3D. Escolha um cartão na página da coleção ou abra qualquer jogo pelos links abaixo. 👻

Gostou do clube? **[Dê uma estrela ao halloween-games](https://github.com/AshinTop/halloween-games)** para encontrá-lo de novo e acompanhar as melhorias.

A coleção mantém o azul da meia-noite, a luz quente da lua, o fantasma flutuante e os cartões ilustrados do projeto original. **Os 12 jogos aparecem por padrão.** O seletor alterna a página entre inglês e chinês simplificado; os filtros mostram os seis primeiros jogos, as seis aventuras adicionais ou a coleção completa.

**Idiomas:** a coleção e as interfaces dos jogos oferecem **inglês e chinês simplificado**. Os guias README existem em cinco idiomas; isso não significa que os jogos tenham interface em português, espanhol ou japonês.

## 🌙 Jogando no clube

Clique em um cartão para abrir a janela do jogo em toda a área do navegador. **Back** volta à coleção; **Open separately** abre o mesmo jogo da Cloudflare em outra aba. Fechar a janela do jogo descarrega o iframe e interrompe sua música. Cliques com teclas modificadoras mantêm o comportamento normal do navegador.

Use os botões visíveis ou os controles de teclado indicados em cada jogo. A música começa depois de uma ação do jogador. Cada jogo salva o progresso no armazenamento do navegador quando disponível; as configurações podem isolar o armazenamento de iframes. Escolha Open separately para acessar diretamente. Os doze links reais já estão no HTML original e continuam acessíveis sem o script da coleção; os jogos precisam de JavaScript para funcionar.

## 🛠️ Executar a coleção localmente

Na raiz deste repositório, execute:

```sh
python3 -m http.server 8080
```

Abra **http://localhost:8080/**. Não é necessário instalar dependências nem executar uma etapa de compilação. A página usa HTML, CSS, JavaScript e ilustrações SVG locais; cada jogo é carregado a partir de seu domínio existente `*.crazy3d.org`. Portanto, é preciso acesso à internet para carregar os jogos hospedados.

Você pode conferir a sintaxe do script com:

```sh
node --check club.js
```

## 🚀 Publicação estática

Publique a raiz do repositório como um diretório estático. No **GitHub Pages**, escolha **Deploy from a branch → main → /(root)** e mantenha `.nojekyll`. No **Cloudflare Pages**, use a configuração de HTML estático e publique o diretório que contém `index.html`; se precisar de um comando sem compilação, use `exit 0`.

A coleção já está publicada no GitHub Pages: **[Abrir Midnight Candy Club](https://ashintop.github.io/halloween-games/)**. Os doze links acima já apontam para os jogos ativos na Cloudflare. Os arquivos relativos também funcionam no subcaminho de um repositório do GitHub Pages.

Documentação da hospedagem: [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) · [Cloudflare Pages — Static HTML](https://developers.cloudflare.com/pages/framework-guides/deploy-anything/).

## 📁 Uma coleção pequena e independente

- `index.html` — catálogo estático completo, doze links ativos, textos bilíngues, ilustrações e metadados `ItemList`.
- `club.css` — estilo original do clube, cartões responsivos, foco acessível e layout da janela do jogo.
- `club.js` — seleção de idioma, filtros, diálogo e abertura progressiva de iframes.
- `club.svg` / `favicon.ico` — o ícone do fantasminha do clube.
- `.nojekyll` — publicação estática direta no GitHub Pages.

O código de cada jogo permanece em seu próprio repositório. A coleção não duplica os doze jogos, arquivos de mídia ou credenciais de publicação. Para mudar um cartão, edite o link e os textos `data-en` / `data-zh` em `index.html`.
