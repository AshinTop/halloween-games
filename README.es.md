# 🎃 Juegos de Halloween — 12 minijuegos gratis para el navegador

**Midnight Candy Club** reúne doce juegos acogedores de Halloween: números de calabaza, solitario encantado, bloques de caramelo, fantasmas reflejados, música de monstruos, ritmo y pequeñas aventuras 3D. Elige una tarjeta en la página de la colección o abre cualquiera de los juegos en los enlaces de abajo. 👻

¿Te gusta el club? **[Dale una estrella a halloween-games](https://github.com/AshinTop/halloween-games)** para encontrarlo fácilmente y seguir sus mejoras.

La colección conserva el azul de medianoche, la luz cálida de la luna, el fantasma flotante y las tarjetas ilustradas del diseño original. **Los 12 juegos aparecen por defecto.** El selector cambia la página entre inglés y chino simplificado; los filtros muestran los seis primeros juegos, las seis aventuras adicionales o toda la colección.

**Idiomas:** la colección y las interfaces de los juegos admiten **inglés y chino simplificado**. Las guías README están disponibles en cinco idiomas; esto no significa que los juegos tengan interfaz en español, portugués o japonés.

## 🌙 Jugar desde el club

Pulsa una tarjeta para abrir el reproductor a tamaño de ventana. **Back** o **Esc** vuelve a la colección; **Open separately** abre el mismo juego de Cloudflare en otra pestaña. Al cerrar el reproductor se descarga el iframe y se detiene su música. Los clics con teclas modificadoras conservan su comportamiento habitual.

Usa los botones visibles o los controles de teclado indicados por cada juego. La música comienza tras una acción del jugador. Cada juego guarda su progreso en el almacenamiento del navegador cuando está disponible; la configuración del navegador puede aislar el almacenamiento de un iframe. Elige Open separately para acceder directamente. Los doce enlaces reales ya están en el HTML original y siguen disponibles sin el script de la colección; los juegos sí necesitan JavaScript.

## 🛠️ Ejecutar la colección en local

Desde la raíz de este repositorio, ejecuta:

```sh
python3 -m http.server 8080
```

Abre **http://localhost:8080/**. No hace falta instalar dependencias ni ejecutar una compilación. La página usa HTML, CSS, JavaScript y dibujos SVG locales, mientras que los juegos se cargan desde sus dominios existentes `*.crazy3d.org`. Por ello, se necesita conexión para cargar los juegos alojados.

Puedes comprobar la sintaxis del script con:

```sh
node --check club.js
```

## 🚀 Publicación estática

Publica la raíz del repositorio como directorio estático. En **GitHub Pages**, selecciona **Deploy from a branch → main → /(root)** y conserva `.nojekyll`. En **Cloudflare Pages**, utiliza la configuración de HTML estático y publica la carpeta que contiene `index.html`; si necesitas un comando de compilación sin acciones, usa `exit 0`.

El servicio de alojamiento proporciona la dirección definitiva de la colección después del despliegue. Los doce enlaces anteriores ya apuntan a sus juegos activos en Cloudflare. Los recursos relativos también funcionan bajo la subruta de un repositorio de GitHub Pages.

Documentación del alojamiento: [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) · [Cloudflare Pages — Static HTML](https://developers.cloudflare.com/pages/framework-guides/deploy-anything/).

## 📁 Una colección pequeña e independiente

- `index.html` — catálogo estático completo, doce enlaces activos, textos bilingües, ilustraciones y metadatos `ItemList`.
- `club.css` — estilo original del club, tarjetas adaptables, indicadores de foco y diseño del reproductor.
- `club.js` — idioma, filtros, diálogo y apertura progresiva de iframes.
- `club.svg` / `favicon.ico` — el icono del pequeño fantasma.
- `.nojekyll` — publicación estática directa en GitHub Pages.

El código de cada juego permanece en su repositorio enlazado. Este proyecto no duplica los doce juegos, archivos multimedia ni credenciales de despliegue. Para cambiar una tarjeta, edita su enlace y los textos `data-en` / `data-zh` en `index.html`.
