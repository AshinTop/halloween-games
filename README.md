# 🎃 Halloween Games — 12 Free Browser Mini Games

**[🎃 Play all 12 Halloween games online →](https://ashintop.github.io/halloween-games/)**

**Midnight Candy Club** is a cozy collection of twelve Halloween games: pumpkin number puzzles, haunted solitaire, candy blocks, mirrored ghosts, monster music, rhythm play, and little 3D adventures. Choose a card on the collection page to open its player, or follow any live game link below. 👻

Enjoy the club? **[Give halloween-games a star](https://github.com/AshinTop/halloween-games)** to keep the collection close and follow new improvements.

The collection keeps the original midnight-blue palette, warm moonlight, floating ghost, and illustrated cards. **All 12 games are visible by default.** The language toggle changes the collection between English and Simplified Chinese; filters show the first six, the six additional adventures, or everything together.

**Language note:** the collection and the games support **English and Simplified Chinese**. These README guides are available in five languages; Spanish, Portuguese, and Japanese gameplay interfaces are not included.

## 🌙 Playing from the club

Click a game card to open a full-window player. **Back** returns to the collection, and **Open separately** opens the same Cloudflare game in its own tab. Closing the player unloads the frame so its music stops. Modified link clicks still work normally.

Use each game’s visible buttons or its documented keyboard controls. Music starts after a player action. Progress is stored by each game in browser storage when available; embedded storage can be isolated by browser settings. If you want to use the game directly, choose Open separately. The catalogue’s twelve real links are present in the original HTML, so they remain available without the collection script; the games themselves need JavaScript.

## 🛠️ Run the collection locally

From this repository’s root, run:

```sh
python3 -m http.server 8080
```

Open **http://localhost:8080/**. No dependency install or build command is required. The page uses local HTML, CSS, JavaScript, and SVG artwork, while each playable game loads from its existing `*.crazy3d.org` origin. Internet access is therefore needed to load the hosted games.

A quick syntax check is available with:

```sh
node --check club.js
```

## 🚀 Static deployment

Publish the repository root as a static directory. For **GitHub Pages**, choose **Deploy from a branch → main → /(root)** and retain `.nojekyll`. For **Cloudflare Pages**, use the static HTML configuration and publish the directory containing `index.html`; an optional no-op build command is `exit 0`.

The collection is live on GitHub Pages: **[Open Midnight Candy Club](https://ashintop.github.io/halloween-games/)**. All twelve game links above already point to their live Cloudflare origins. Relative collection assets also work under a GitHub Pages repository subpath.

Hosting references: [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) · [Cloudflare Pages — Static HTML](https://developers.cloudflare.com/pages/framework-guides/deploy-anything/).

## 📁 Small, independent collection

- `index.html` — the complete static catalogue, twelve live links, bilingual copy, inline illustrations, and `ItemList` metadata.
- `club.css` — the original club styling, responsive cards, focus states, and player layout.
- `club.js` — language selection, filters, dialog controls, and progressive iframe launching.
- `club.svg` / `favicon.ico` — the club’s ghost icon.
- `.nojekyll` — direct static publishing on GitHub Pages.

Each game’s source stays in its own linked repository. This project does not duplicate the twelve game codebases, media archives, or deployment credentials. To change a card, edit its static link and bilingual `data-en` / `data-zh` text in `index.html`.
