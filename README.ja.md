# 🎃 ハロウィンゲーム集 — ブラウザーで遊べる無料ミニゲーム12作品

**Midnight Candy Club** は、カボチャの数字パズル、幽霊のソリティア、お菓子のブロック、鏡の幽霊、モンスター音楽、リズムゲーム、小さな3D冒険を集めた、やさしい雰囲気のハロウィンゲーム集です。コレクションのカードからプレイヤーを開くか、下の各ゲームへのリンクで遊べます。👻

クラブが気に入ったら、**[halloween-games に Star を付けてください](https://github.com/AshinTop/halloween-games)**。また訪れたり、今後の改良を見つけたりしやすくなります。

最初のデザインのミッドナイトブルー、暖かい月明かり、浮かぶ幽霊、イラスト入りカードを引き継いでいます。**初期表示では12作品すべてが見えます。** ページは英語と簡体字中国語に切り替えられ、フィルターで最初の6作品、追加の6作品、全作品を選べます。

**言語について：**コレクションとゲーム画面の対応言語は**英語と簡体字中国語**です。README は5言語で読めますが、日本語・スペイン語・ポルトガル語のゲーム画面を実装したという意味ではありません。

## 🌙 クラブから遊ぶ

カードをクリックすると、ウィンドウいっぱいのプレイヤーが開きます。**Back** または **Esc** で一覧に戻り、**Open separately** で同じ Cloudflare のゲームを別タブに開けます。プレイヤーを閉じると iframe を取り外すため、ゲームの音楽も止まります。修飾キーを押しながらのクリックは、ブラウザー本来の動作を保ちます。

各ゲームの画面ボタンや説明にあるキーで操作してください。音楽はプレイヤーの操作後に始まります。利用できる場合はブラウザー内に進行状況を保存しますが、埋め込み画面の保存領域がブラウザー設定で分離されることもあります。直接アクセスしたい場合は Open separately を使えます。12の実リンクは元の HTML に含まれているため、一覧のスクリプトが動かなくても開けます。ただしゲームの動作自体には JavaScript が必要です。

## 🛠️ ローカルで起動する

このリポジトリのルートで実行します：

```sh
python3 -m http.server 8080
```

**http://localhost:8080/** を開いてください。依存パッケージのインストールやビルドは不要です。一覧はローカルの HTML、CSS、JavaScript、SVG を使い、ゲーム本体は既存の `*.crazy3d.org` から読み込みます。そのため、公開中のゲームを読み込む際にはインターネット接続が必要です。

スクリプトの構文は次のコマンドで確認できます：

```sh
node --check club.js
```

## 🚀 静的サイトとして公開する

リポジトリのルートを静的ディレクトリとして公開します。**GitHub Pages** では **Deploy from a branch → main → /(root)** を選び、`.nojekyll` を残してください。**Cloudflare Pages** では静的 HTML の設定で `index.html` を含むディレクトリを公開します。ビルド不要のコマンドが必要な場合は `exit 0` を使えます。

コレクションの最終 URL はデプロイ後にホスティングサービスから提供されます。上の12作品へのリンクは、すでに公開されている Cloudflare のゲームを指しています。相対パスの資産は GitHub Pages のリポジトリ配下でも利用できます。

ホスティングの参考資料: [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) · [Cloudflare Pages — Static HTML](https://developers.cloudflare.com/pages/framework-guides/deploy-anything/).

## 📁 小さく独立したコレクション

- `index.html` — 完全な静的一覧、12の公開リンク、2言語の文面、インラインのイラスト、`ItemList` メタデータ。
- `club.css` — クラブ本来の外観、可変幅カード、フォーカス表示、プレイヤー配置。
- `club.js` — 言語、フィルター、ダイアログ、iframe 起動の段階的な拡張。
- `club.svg` / `favicon.ico` — クラブの小さな幽霊アイコン。
- `.nojekyll` — GitHub Pages で静的ファイルをそのまま公開するためのファイル。

ゲーム本体のソースは各リンク先のリポジトリにあります。このプロジェクトは12作品のコード、メディア一式、公開用の認証情報を複製しません。カードを変えるときは `index.html` のリンクと `data-en` / `data-zh` の文面を編集してください。

## 💛 クレジットとフィードバック

**AshinTop** と **Midnight Candy Club** のために、人が方向を定める AI 協働でデザイン、実装、文章、レビューを行いました。コレクションは元のクラブの SVG イラストとビジュアルを再利用しています。各ゲームの実装と説明は、上のソースリンクから確認できます。

コレクションのコードは、選択した表示言語をローカルに保存します。各ゲームの保存領域や、ホスティング側のスクリプト・リクエストログはそれぞれのサイトで扱われます。コレクションの利用にアカウントは必要ありません。

問題を見つけたら、ゲーム名、直接 URL、ブラウザー、ウィンドウの大きさ、再現手順を添えてください。気に入った小さな幽霊屋敷にまた帰れるように、**[クラブに Star を付けてください](https://github.com/AshinTop/halloween-games)**。
